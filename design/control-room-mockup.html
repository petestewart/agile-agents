Brieforacle/product.md

Product

ledger-lite is a tiny in-memory personal ledger: accounts, integer-cent transactions, balances and monthly summaries.

Non-goals

Persistence, authentication, a UI, multi-currency conversion.

Glossary

Transaction: an account, a signed integer amount in cents (positive = deposit), an ISO date, a memo, an optional category.
Reversal: a new transaction that negates an earlier one. The original is never touched.
Transfer: two transactions, a withdrawal and a deposit, recorded together.

Current goal

Add transfers, reversals and a per-category spending breakdown, keeping money in integer cents and the ledger append-only.

Rules (2)oracle/specs/SPEC-*.md
SPEC-quality-001 Code quality baseline active

1. Every public function validates its inputs and throws a descriptive Error on invalid input, never a silently wrong result.
2. Money is always integer cents; no floating-point arithmetic on amounts.
3. No console.log or console.debug ships in src/.
4. Every new behaviour has a test in test/ and bun test stays green.

Applies to: every ticket · Drafted by the architect from README.md and existing tests · Edit · History
SPEC-ledger-002 Transactions are immutable once recorded active

Once recorded, a transaction is never edited or deleted. A correction is a new transaction that reverses the original: same account, negated amount, memo referencing the original id.

Applies to: TKT-2002, TKT-2004 · From your brief · Edit · History
