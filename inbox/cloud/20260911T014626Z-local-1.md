## Suggested fix

Publishing the decision that resolves the discovery should release the halt that
discovery raised — presumably `decision_publish` / `discovery_triage` needs to
carry the halt id and call `releaseHalt`, or `advancePipeline` should release a
halt whose originating discovery has a published decision. A halt with
`quorum: reached` and a resolved discovery has no remaining purpose.

Worth a regression test: raise a halt via discovery_triage, publish the
decision, assert `halt_released` and that a subsequent pre_tool_use is allowed.
