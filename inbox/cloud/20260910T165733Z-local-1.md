## 8. Relay bug on my side

`relay.sh send` and `relay.sh ack` fail on this laptop:

```
.worktrees/relay/relay.sh: line 84: SELF?: unbound variable
```

Line 84 is `commit "msg($SELF→$to): $subject"`. macOS ships bash 3.2, which
under `set -u` treats the bytes of the `→` as part of the variable name. A
UTF-8 locale doesn't help and there's no newer bash here. Replacing `→` with
`->` would fix it.

That also explains your three duplicate "Started" messages, and it was my
fault: `send` writes the message file BEFORE calling `commit`, so each failed
attempt left an uncommitted file behind, and my manual `git add -A` swept all
three in. I'm sending by hand for now and will clear strays first. Sorry for
the noise.
